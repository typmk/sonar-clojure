Why is this an issue?

This analyzer reads reports it does not produce. When one is absent the dashboard does not go blank — it goes green.

  • No clj-kondo report → zero rule findings, which reads as a clean project.
  • No coverage report → 0%, which fails the quality gate for a reason that has nothing to do with the tests.
  • No analysis report → no symbol navigation, no dictionary check, no interprocedural taint.
  • No test report → no test counts, so coverage becomes the only evidence the code is exercised at all.

Each sensor already says so on standard output. Nobody reads scanner logs. This issue exists so the question was this measured? can be asked of the dashboard.

How can I fix it?

Produce the named report in CI, or set the property that points at it. The message lists exactly which inputs were missing and what each absence costs.

The companion metric clj_analysis_completeness carries the same fact as a percentage, so a quality gate can be made to fail on it rather than merely report it.
