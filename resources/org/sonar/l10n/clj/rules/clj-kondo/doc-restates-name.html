Why is this an issue?

"Parses the config." on parse-config: every content word of the docstring is a token of the name. The reader learns nothing the name did not already say, and every tool that checks for a docstring reports the function as documented.

How can I fix it?

Say what the function guarantees or returns: the input's shape, the edge case, what nil means. If there is nothing to add, the docstring is the name and can go.
