Why is this an issue?

hiccup escapes the strings it renders. raw exists to opt out of that, so a raw call on a computed value puts unescaped, possibly attacker-controlled markup into the page.

How can I fix it?

Render the value normally and let hiccup escape it. If markup really is intended, sanitise it first.
