Why is this an issue?

CLAUDE.md opens with The enemy of progress is inconsistency and carries a Banned → use table. A word means its entry; the same spelling is not the same thing across layers; one term per concept, no aliases.

Two names for one concept is how a model drifts: the code stops answering the question the dictionary asks of it, and a reader cannot tell whether a difference in wording marks a difference in meaning.

How can I fix it?

Use the canonical term. The message names it.

:dimension   → :facet
:slot        → :taxon/factor
:custody     → :controller | :operator | :key-holder
:visibility  → :scope
:entry       → :event

If the banned term genuinely names something new, the dictionary is what changes -- not the code around it.
